# pos-sync-public

FWに乗らないPOS（ダイニー / 新Uレジ）の売上・原価を取り込む。
手順と仕様は [README_POS連携.md](./README_POS連携.md) を参照。

## このリポジトリが公開な理由

GitHub Actions は公開リポジトリなら実行時間が無制限（非公開は月2,000分）。
非公開だった旧 `pos-sync` は無料枠を使い切り、ジョブが起動しなくなったため移設した。

**公開なので、実行ログも artifact も誰でも見られる。**
認証情報はすべて GitHub Secrets 経由で、コードには書かない。
売上の数字が写るもの（スクリーンショット・HTML・CSVの実体）は、
`diag_files=1` を明示したときだけ出力する（既定は出さない）。
